Added an experimental, off-by-default setting (Settings → Audio) that shows a
button to play an entry's readings as audio, with a karaoke-style overlay
highlighting each mora as it's spoken. Playing audio sends the displayed
reading (and any kanji) to 10ten's audio server to fetch the clip. Press
<kbd>p</kbd> to start or stop the first entry's readings.
